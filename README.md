Problem statement:
--------------------
Managing personal tasks manually can lead to missed deadlines. 
This system helps by managing all tasks in one place, 
by categorizing them for better organiztion, and reminding users before deadlines. 

Setup Instructions:
-------------------
1. Clone the Repository:
   
    git clone (https://github.com/luser-hash/luser-hash-Ostad-Django-assingment-Module-19.git)
    cd taskmanager

3. Create and Activate Virtual Environment.
   

4. Install Dependencies, Make sure your virtual environment is activated, then run:
   
    pip install -r requirements.txt

5. Apply Migrations:
   
    python manage.py makemigrations
    python manage.py migrate

6. Create Superuser (optional
   
    python manage.py createsuperuser

7. Run the Development Server:
   
    http://127.0.0.1:8000/tasks/
    
8. Access the App
